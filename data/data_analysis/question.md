## 1. Query Breakdown（圖表 08）

**是什麼：** 「各搜尋標籤的蒐集結果對比」，分左右兩欄：

| 欄位 | 說明 |
|------|------|
| Videos Collected per Query | 每個標籤蒐集到幾支影片 |
| Avg Views per Query | 每個標籤影片的平均觀看數 |

**三個標籤：** `#ai`、`#ai #girl`、`#ai #cat`

**用途：** 讓你知道哪個主題的資料量最多、哪個主題的影片平均表現最好。

**範例解讀：**

```
#ai         → 150 支，平均 82,000 次觀看
#ai #girl   →  95 支，平均 210,000 次觀看
#ai #cat    →  80 支，平均 54,000 次觀看
```

→ 雖然 `#ai #girl` 蒐集筆數較少，但平均觀看數最高，代表這個主題的影片傳播力更強。

## 2. Engagement Rate（互動率）

**計算公式：**

```
engagement_rate = (likes + comments) / views
```

**是什麼：** 衡量觀眾「看了之後有沒有主動互動」的指標，純觀看不算，點讚或留言才算。

| 數值 | 意義 |
|------|------|
| 高 engagement rate | 觀眾被內容打動，願意花時間互動 |
| 低 engagement rate | 只是被演算法推送、被動觀看，沒有共鳴 |

**與觀看數的差別：**

- 觀看數高 ≠ 互動率高（例如被洗版推播但內容無聊）
- 互動率高 = 觀眾真的對內容有感，對品牌經營更有價值

**在本專案中的應用（象限分析圖）：**

| 象限 | 觀看數 | 互動率 | 含義 |
|------|--------|--------|------|
| Viral Star | 高 | 高 | 爆款，又紅又有共鳴 |
| Rising Star | 低 | 高 | 潛力股，還沒爆但觀眾很喜歡 |
| High Traffic | 高 | 低 | 流量大但觀眾冷漠，可能靠標題黨 |
| Low Key | 低 | 低 | 沒有突出表現 |

## 3. Top Channels（圖表 07）——統計的是什麼流量？

**答：是「頻道在本資料集內的累積流量」，不是頻道的全站總流量。**

### 計算邏輯

```
某頻道的總觀看數 = 該頻道所有被蒐集到的影片的觀看數加總
```

程式碼：
```python
df.groupby("channel_title")["views"].sum().nlargest(15)
```

### 舉例說明

假設資料庫中有以下資料：

| 影片標題 | 頻道 | 觀看數 |
|----------|------|--------|
| AI畫出超真實貓咪 | CatWorld | 500,000 |
| AI生成貓咪語音 | CatWorld | 300,000 |
| 用AI做貓咪濾鏡 | CatWorld | 200,000 |
| AI女孩動畫教學 | AIArt Studio | 800,000 |

→ Top Channels 圖表中：
- **CatWorld** 顯示 **1,000,000**（三支影片加總）
- **AIArt Studio** 顯示 **800,000**（一支影片）

**結論：** Top Channels 排的是「哪個頻道在我們蒐集的 Shorts 裡貢獻了最多觀看次數」，反映的是**在 #ai 系列短影音市場中最具影響力的頻道**，而非 YouTube 全站的頻道排行。
